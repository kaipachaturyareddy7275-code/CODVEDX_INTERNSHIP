## ⚙️ How to Run the Projects

**HTML, CSS and JavaScript projects**

1. Open the respective project folder.
2. Open `index.html` in your browser.
3. Alternatively, use the VS Code Live Server extension.

**React E-commerce frontend**

```bash
cd "E-commerce internship project/client"
npm install
npm start
```

If the project uses Vite, use `npm run dev` instead.

**Node.js backend**

Open the respective backend folder:

```bash
npm install
node server.js
```

Check the `package.json` scripts and configure the required environment variables before running the backend.
